第二話

Esta é a
máquina.
Ao vivo.

É o overlay do repositório rodando no seu navegador (nada de vídeo), tocando a mesma sessão do ryoiki demo. Um pedido, um teste que quebra, falhas em sequência e, no fim, testes verdes.

  • 領域展開Você manda o prompt e o domínio se abre.
  • 回転Cada ferramenta gira os rolos. Editar fecha as portas; ler ou rodar comando acende uma bola de reserva.
  • リーチSeus testes estão rodando. O resultado real fica na linha da conversa: ✓ 12 ou ✗ 1/12.
  • あなたの番O agente precisa de você. Nas linhas com ↗, um clique abre a conversa no app do Claude.

Fontes, e onde o mangá não diz nada
  • As regras vêm da folha de regras do CR私鉄純愛列車 mostrada no capítulo 183 de Jujutsu Kaisen e das lutas dos capítulos 182 a 190. Ligar eventos do agente a eventos da luta é escolha do projeto.
  • A probabilidade aumentada é 1/24; o 疑似連 falha metade das vezes fora dela (10% dentro); o 潜伏確変 vem em 25% dos jackpots pares. O mangá não dá esses números.
  • A história do riichi 座席争奪 nunca foi mostrada, então as falas dele são inventadas.

景品

Troque três
passos pelo prêmio.

Precisa do Node.js 20 ou mais novo e do Claude Code. Sem conta e sem telemetria.

01景品券

Instale

git clone https://github.com/tiagocardosobezerra/zasatsu-bakuto.git
cd zasatsu-bakuto
npm install
npm link

O npm link cria o comando ryoiki. O npm 11 pode pedir para aprovar o Electron: npm install-scripts approve electron.

02景品券

Ligue no Claude Code

ryoiki install

Põe os hooks e a linha de status em ~/.claude/settings.json e guarda um backup. Sua linha de status continua igual e volta inteira no ryoiki uninstall.

03景品券

Abra o domínio

ryoiki tenkai

領域展開. A máquina aparece no canto e acorda no seu primeiro prompt. Para ver antes, rode ryoiki demo.

おまけ

Extras do
volume.

配信

Na live

Rode ryoiki serve e adicione http://127.0.0.1:4111/ como browser source no OBS, com fundo transparente. Canto, tamanho e formato vão na URL.

静

No trabalho

O modo discreto deixa a máquina pequena, sem som, sem tela cheia e um pouco transparente. Formatos Normal, Compacto e Mini.

他

Outras IAs

A máquina escuta uma API local: qualquer agente que mande um POST para /event no formato dos hooks pode jogar. Codex CLI, Gemini CLI, Cursor e Aider ainda não têm adaptador pronto.

私

Suas artes

O app não traz imagens nem músicas da obra: tudo é CSS e som sintetizado. Arquivos seus em ~/.zasatsu-bakuto/custom/ trocam rolos, fundo, jackpot e sons e ficam só na sua máquina. Você responde pelos direitos sobre eles.

注意

Leia antes
de jogar.

○ 安全

Nunca atrapalha o agente.

O hook repassa o evento e sai na hora: nunca imprime, nunca bloqueia, sempre sai com código 0. O overlay deixa o clique passar.

○ ローカル

O que a máquina vê fica no seu PC.

Tudo roda em 127.0.0.1, sem telemetria nem conta, e o servidor recusa páginas de outros sites. Só as fontes da tela vêm do Google Fonts.

○ 配慮

Respeita quem pede menos movimento.

Com o ajuste do sistema ligado, os efeitos ficam na máquina e nada treme ou pisca forte.

○ 保存

Mexe no settings.json com cuidado.

Grava por arquivo temporário, guarda o backup de antes e o ryoiki status avisa se os hooks quebraram.

× 非対応

Uso do plano não aparece no app desktop.

Os números vêm da linha de status, que o Claude Code do terminal roda e o app desktop não. Com chave de API, as pizzas ficam escondidas.
